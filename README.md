# KEYVERSE — Master Your Keyboard. Beat Your Limits.

**KEYVERSE** is a modern, interactive typing challenge game designed to improve keyboard accuracy, speed, and typing confidence through engaging arcade-style gameplay.

Featuring two unique game modes, responsive layouts, difficulty settings, real-time statistics, and interactive feedback, KEYVERSE turns everyday typing practice into an exciting challenge.

## ✨ Features

- **Bubble Rush:** Recognize and type falling letters before they reach the bottom.
- **KeyMagnet:** Test keyboard precision by responding to dynamically generated key targets.
- **Multiple Difficulty Levels:** Choose Easy, Medium, or Hard for different gameplay challenges.
- **Live Game Statistics:** Track score, accuracy, time, and performance.
- **Interactive Feedback:** Get immediate responses for correct and incorrect inputs.
- **Sound Effects:** Enhance gameplay with interactive audio feedback.
- **Responsive Design:** Enjoy the experience across desktop and mobile screens.
- **Game Controls:** Start, pause, restart, and reset gameplay without reloading the page.

## 🎮 Game Modes

### 1. Bubble Rush
A fast-paced letter recognition challenge. Type the correct letter to pop its matching bubble before it reaches the boundary.

### 2. KeyMagnet
A keyboard precision challenge where players respond to target letters and improve their typing accuracy and reaction time.

## 🚀 Getting Started

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/keyverse-typing-challenge.git
   ```

2. Open the project folder in Visual Studio Code.

3. Install the **Live Server** extension if it is not already installed.

4. Right-click `index.html`.

5. Select **Open with Live Server**.

6. Start playing!
